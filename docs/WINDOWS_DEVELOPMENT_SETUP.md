# Windows development setup — v0.23.0

Use Windows 10/11, Node 20+, npm, Dota 2 and an **approved/whitelisted Overwolf Electron application**. Run `scripts/windows/setup-dev.ps1`, then `start-mock.ps1`, `start-replay.ps1 <jsonl>`, or `start-live.ps1`. Scripts install no system software, change no policies and require no administrator access. `-gamestateintegration` cannot be reliably inspected by Dota Flow; confirm it manually.
