# v0.22 Product UX Status

The simulator-first Scenario Workbench lists provider-owned scenarios, filters mode/search, runs entries, and exposes checkpoints, forbidden calls, reasons, missing signals, quality, suppression, trace, review metrics, and golden diff. Mock and replay providers implement scenario methods; Electron IPC fails closed.

This release does **not** validate Windows packaging, signing, production overlay behavior, or a real Overwolf GEP. Fixtures are synthetic. Real match vision, buyback, inventory completeness, routes, readiness, and outcomes remain manual/inferred where absent. Vite build status must be reported from the actual `npm run desktop:build` result.
