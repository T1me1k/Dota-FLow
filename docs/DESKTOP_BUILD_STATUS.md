# Desktop Build Status

`npm run desktop:validate` performs offline source/contract validation and does not claim to produce a bundle. `npm run desktop:build` is the real Vite production command and fails when frontend dependencies are absent. Installing/building requires the standard npm registry. Windows Electron/Overwolf integration and visual browser validation remain unperformed in this Linux hardening pass; no screenshot is claimed.

On 2026-08-01, the standard `npm --prefix apps/desktop install --package-lock-only --ignore-scripts` attempt failed with npm registry HTTP 403 for `@types/react`. Consequently the real build was attempted and failed honestly with `vite: not found` (exit 127). TypeScript contracts were checked with the environment-provided compiler, but no production bundle or visual test is claimed. No lockfile was generated by the failed registry operation.
